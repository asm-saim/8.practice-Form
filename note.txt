================================================================
                    HTML FORMS GUIDE
================================================================

An HTML form is used to collect user input and send it to a
server. Here's a breakdown of the key elements and attributes.

----------------------------------------------------------------
1. THE <form> ELEMENT
----------------------------------------------------------------

Example:
  <form action="/submit" method="POST">
    <!-- form elements go here -->
  </form>

Key Attributes:
  - action      : URL where form data is sent
  - method      : HTTP method: GET or POST
  - enctype     : Encoding type (e.g., multipart/form-data for files)
  - target      : Where to display the response (_self, _blank, etc.)
  - novalidate  : Disables browser validation

----------------------------------------------------------------
2. COMMON FORM ELEMENTS
----------------------------------------------------------------

>> <input> — Most versatile element, controlled by "type":

  Type         | Purpose
  -------------|-------------------------
  text         | Single-line text
  password     | Masked text
  email        | Email with validation
  number       | Numeric input
  checkbox     | Toggle on/off
  radio        | Select one from a group
  file         | File upload
  submit       | Submit the form
  reset        | Clear all fields
  hidden       | Invisible data field
  date / time  | Date/time pickers
  range        | Slider
  color        | Color picker

--

>> <textarea> — Multi-line text input:

  <textarea name="message" rows="4" cols="50"></textarea>

--

>> <select> & <option> — Dropdown list:

  <select name="country">
    <option value="bd">Bangladesh</option>
    <option value="us">USA</option>
  </select>

--

>> <button> — Clickable button:

  <button type="submit">Send</button>
  <button type="reset">Clear</button>
  <button type="button">Custom Action</button>

--

>> <label> — Links text to an input (improves accessibility):

  <label for="email">Email:</label>
  <input type="email" id="email" name="email">

--

>> <fieldset> & <legend> — Groups related fields:

  <fieldset>
    <legend>Personal Info</legend>
    <!-- inputs here -->
  </fieldset>

----------------------------------------------------------------
3. IMPORTANT <input> ATTRIBUTES
----------------------------------------------------------------

  Attribute      | Purpose
  ---------------|----------------------------------------
  name           | Key used when submitting data
  id             | Links with <label>
  value          | Default or submitted value
  placeholder    | Hint text inside the field
  required       | Makes field mandatory
  disabled       | Disables the field
  readonly       | Visible but not editable
  maxlength      | Max character limit
  min / max      | Range for number/date inputs
  pattern        | Regex validation
  autofocus      | Auto-focuses on page load
  autocomplete   | Enables/disables autocomplete

----------------------------------------------------------------
4. A COMPLETE EXAMPLE
----------------------------------------------------------------

  <form action="/register" method="POST">

    <label for="name">Name:</label>
    <input type="text" id="name" name="name"
           placeholder="Your name" required>

    <label for="email">Email:</label>
    <input type="email" id="email" name="email" required>

    <label for="gender">Gender:</label>
    <select id="gender" name="gender">
      <option value="male">Male</option>
      <option value="female">Female</option>
    </select>

    <label>
      <input type="checkbox" name="agree" required>
      I agree to terms
    </label>

    <button type="submit">Register</button>

  </form>

----------------------------------------------------------------
NOTE:
Forms are the backbone of user interaction on the web —
login pages, search bars, contact forms, and checkouts
all rely on them.
